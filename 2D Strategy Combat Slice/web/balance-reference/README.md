# Astro Fighters — Balance Reference Index

This folder is the web-local reference set for the 2026-08-12 DC / CC / DOT / action-slot / resource-cost balance phase. It is intentionally separate from runtime JS/HTML so analysis material does not accumulate in the active web implementation namespace.

## Owner-locked rules

- Intrinsic CC/DOT tier is **not** the same as final action-slot cost.
- Equal-investment post-hit rider targets: **C 60%, B 45%, A ~35%, S ~30%**.
- Standard damaging melee-Stamina rider floors: **C 10, B 12, A 15, S 20, S+Guard Break 25**.
- Pure A and Pure S control must cost more resource than damaging riders of the same tier.
- Comparable resource hierarchy is intentional: **melee Stamina < ranged Stamina < Chakra**.
- Kyudo/ranged-Stamina abilities intentionally pay more Stamina because range is itself an advantage.
- Guard Break and harmful-status premiums must remain visible in every resource channel consumed.
- Extra action slots supplement resource premiums; they do not replace them.
- Sweeping Low is allowed to remain 1 slot while paying the full S-tier Stamina premium so the approved Karate five-action string remains legal.

## Current recommended candidate — not yet owner-locked

```text
StatEdge = clamp(trunc((AttackerControlStat - DefenderSaveStat) / 5), -6, +6)
MasteryBonus = floor(AbilityLevel / 4)
DC = TierOffset + StatEdge + MasteryBonus
TierOffset C/B/A/S = 13/10/8/7
Natural 1 save -> status lands
Natural 20 save -> resisted
```

This candidate survived the career-stat and 170-ability roster simulations. It is now also implemented in **shadow/test code** at `../af-dc-model-v3.js`; live `applyStatus` still uses authored fixed DCs.

## Test implementation state

- `web/af-dc-model-v3.js` contains the candidate formula and tier/resource/slot audit helpers.
- `web/af-core.smoke.js` loads the shadow module and dynamically audits all Sign + Universal + Martial + Weapon content.
- The smoke uses **coverage invariants**, not permanent exact roster-count assertions, so adding abilities or intentionally converting legacy automatic riders does not make the test obsolete.
- Live player-facing combat is unchanged because the V3.4 runtime/HTML does not load or call the shadow model yet.

## Important interpretation notes

- Use **resolver-true cost**. Elemental Ninjutsu already pays `BAL.elementalCostMult = 1.75`; do not add another blanket Chakra/range tax on top without reconciling it.
- AoE status packages are **single-gate** in the current resolver because `resolveAoe` does not make the normal single-target accuracy roll.
- Grapples remain a separate control lane because they already pay through contests, setup actions, rooting, escape attempts, upkeep, and follow-up dependencies.
- Resource-drain riders and harmful Trap Supply premiums are not fully tiered yet.
- AI planner pick-rate is not valid balance evidence for damaging status riders until `planFor().score()` values damage and rider utility together.
