## Current benchmark-family conclusions

The useful legacy visual language is strongest where it shows:

- pale-to-warm dry matte civic stone;
- irregular authored stone courses rather than obvious tile cadence;
- localized cracks, grime, moss, and repair rather than uniform noise;
- warm aged timber with restrained highlights and darker contact/joinery edges;
- broad plaster planes with localized wear rather than noisy full-surface texture;
- foundations that read older/heavier than street paving;
- clean functional metal accents rather than decorative machinery.

The current family must still be newly authored to these contracted dimensions:

1. `stone-clean` — source 1920×1280 → runtime 192×128
2. `aged-stone-foundation` — source 1920×640 → runtime 192×64
3. `timber-plaster-wall` — source 1920×1600 → runtime 192×160
4. `timber-post` — source 480×1280 → runtime 48×128
5. `horizontal-beam` — source 1280×480 → runtime 128×48
