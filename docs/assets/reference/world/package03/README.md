# Package 03 Reference Anchors

The active Package 03 source material studies cover clean, cracked, patched, and damp Imperial stone. They exist to enforce the locked character-level material-art bar before runtime derivation.

These anchors are **reference-stage quality authorities only**. Checklist completion still requires representative integrated gameplay, architecture, dressing, props, occlusion, a finished production character stack, and the mandatory rubric threshold.

Package 02 and early Package 03 paving studies are superseded and should not be treated as current production targets.
