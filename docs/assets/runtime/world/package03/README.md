# Package 03 Runtime Material Modules

Package 03 v5 uses one authored **128×160** material module at a time for clean, cracked, patched, and damp Imperial stone. The modules are embedded through `docs/js/world-p03-module-data/` and loaded by the Phaser staging bridge.

Do **not** repeat these modules edge-to-edge. Repetition produced visible macro rhythm even though the hidden 32×32 gameplay grid itself was not rendered. The next package adds thresholds and foundations so larger streets can be assembled from authored structural transitions instead of repeated paving blocks.
